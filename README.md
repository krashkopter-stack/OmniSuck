# OmniSuck

Расширение для Chrome, которое качает видео с YouTube, TikTok, Instagram, VK, X и кучи других сайтов. Открыл видео, нажал кнопку — файл в «Загрузках».

С Инстаграмом отдельная фишка: если открыть пост, скачаются сразу все фотки и видео из него, карусели тоже.

Работает на Mac и Windows.

## Что умеет

Внутри всего две кнопки: «Скачать» и «Настройки». В настройках можно выбрать качество, скачать только звук в MP3 или поменять папку.

Пока идёт загрузка, видна полоска с процентами, а значок расширения крутится. Когда всё скачалось — появляется галочка.

Видео всегда сохраняется в обычном MP4, который открывается и в QuickTime, и в монтажке. Если YouTube отдал что-то хитрое (в 4K он так любит), OmniSuck сам перегонит файл, причём старается делать это видеокартой, чтобы не грузить комп.

## Установка

Скачайте файл для своей системы в разделе [Releases](../../releases).

**Mac:** откройте `OmniSuck.dmg`, нажмите правой кнопкой на «Установить.command» и выберите «Открыть».

**Windows:** запустите `OmniSuck-Setup.exe`. Если Windows начнёт ругаться, нажмите «Подробнее» → «Выполнить в любом случае».

Установщик сам скачает всё, что нужно. Минута-две, и готово.

Дальше в Chrome:

1. Откройте `chrome://extensions`
2. Включите «Режим разработчика» справа вверху
3. Нажмите «Загрузить распакованное» и выберите папку *Документы → OmniSuck Extension*

Всё, можно пользоваться.

## Как это устроено

Само расширение лежит в `extension/`. Скачивать видео прямо из браузера нормально не получается, поэтому рядом работает маленькая программка-помощник на Go (`helper/`). Chrome запускает её сам, когда нужно, а она уже вызывает [yt-dlp](https://github.com/yt-dlp/yt-dlp) и [FFmpeg](https://ffmpeg.org).

yt-dlp и FFmpeg в репозитории нет — установщик берёт их с официальных страниц.

Собрать всё самому (нужны Go и Python 3):

```bash
./build.sh
```

Готовые файлы появятся в папке `dist/`.
